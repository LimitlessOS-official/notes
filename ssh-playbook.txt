================================================================================
STEP 10A - PYTHON RAW TCP RELAY
================================================================================

USE THIS WHEN:
    You need to expose a TCP service through a pivot host.

GOOD FOR:
    HTTP
    raw flag ports
    simple TCP services
    sometimes FTP control ports

NOT GOOD FOR:
    Telnet login, unless telnet negotiation is handled elsewhere.

SITUATION:
    Current host can reach TARGET:PORT.
    Blue cannot reach TARGET:PORT.
    Current host has python3.

--------------------------------------------------------------------------------
ON THE PIVOT HOST
--------------------------------------------------------------------------------

Change these values:

    LISTEN_PORT
    TARGET_IP
    TARGET_PORT

Command:

python3 - <<'PY'
import socket
import select

LISTEN_HOST = "0.0.0.0"
LISTEN_PORT = 20810

TARGET_IP = "TARGET_IP_HERE"
TARGET_PORT = 80

ls = socket.socket()
ls.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
ls.bind((LISTEN_HOST, LISTEN_PORT))
ls.listen(5)

print("[+] relay listening on %s:%d -> %s:%d" %
      (LISTEN_HOST, LISTEN_PORT, TARGET_IP, TARGET_PORT), flush=True)

while True:
    client, addr = ls.accept()
    print("[+] client connected:", addr, flush=True)

    remote = socket.socket()
    remote.connect((TARGET_IP, TARGET_PORT))

    sockets = [client, remote]

    try:
        while True:
            readable, _, _ = select.select(sockets, [], [])

            for s in readable:
                data = s.recv(4096)

                if not data:
                    raise Exception("connection closed")

                if s is client:
                    remote.sendall(data)
                else:
                    client.sendall(data)

    except Exception as e:
        print("[+] closed:", e, flush=True)

    try:
        client.close()
    except:
        pass

    try:
        remote.close()
    except:
        pass
PY

================================================================================
STEP 10B - PYTHON TELNETLIB LOGIN
================================================================================

USE THIS WHEN:
    Target is Telnet.
    Normal telnet is blocked.
    /dev/tcp shows gibberish like:

        ��%��&����

WHY:
    That gibberish is Telnet negotiation.
    Raw TCP does not answer it.
    telnetlib does.

--------------------------------------------------------------------------------
CHECK IF TELNETLIB EXISTS
--------------------------------------------------------------------------------

python3 -c "import telnetlib; print('telnetlib OK')"

If it says telnetlib OK, use the script below.

--------------------------------------------------------------------------------
TELNET LOGIN SCRIPT
--------------------------------------------------------------------------------

Change these:

    HOST
    USER
    PASS

Command:

python3 - <<'PY'
import telnetlib
import time
import sys

HOST = "TARGET_IP_HERE"
PORT = 23

USER = b"USERNAME_HERE\n"
PASS = b"PASSWORD_HERE\n"

tn = telnetlib.Telnet(HOST, PORT, timeout=10)

print(tn.read_until(b"login:", timeout=10).decode("latin1", "ignore"), end="")
tn.write(USER)

print(tn.read_until(b"Password:", timeout=10).decode("latin1", "ignore"), end="")
tn.write(PASS)

time.sleep(1)

print(tn.read_very_eager().decode("latin1", "ignore"), end="")

while True:
    cmd = input("$ ")
    tn.write(cmd.encode() + b"\n")
    time.sleep(1)
    print(tn.read_very_eager().decode("latin1", "ignore"), end="")
PY

================================================================================
STEP 10C - ONE-SHOT TELNETLIB COMMAND
================================================================================

USE THIS WHEN:
    You do not need an interactive shell.
    You just want to log in and run one command.

Example:
    Log in by Telnet and run tcpdump.

Change:

    HOST
    USER
    PASS
    COMMAND

Command:

python3 - <<'PY'
import telnetlib
import time
import sys

HOST = "TARGET_IP_HERE"
PORT = 23

USER = b"USERNAME_HERE\n"
PASS = b"PASSWORD_HERE\n"

COMMAND = b"COMMAND_HERE\n"

tn = telnetlib.Telnet(HOST, PORT, timeout=10)

print(tn.read_until(b"login:", timeout=10).decode("latin1", "ignore"), end="")
tn.write(USER)

print(tn.read_until(b"Password:", timeout=10).decode("latin1", "ignore"), end="")
tn.write(PASS)

time.sleep(1)
print(tn.read_very_eager().decode("latin1", "ignore"), end="")

tn.write(COMMAND)

while True:
    data = tn.read_some()
    if data:
        sys.stdout.write(data.decode("latin1", "ignore"))
        sys.stdout.flush()

STEP 11 - TCPDUMP QUESTIONS
================================================================================

Usually:

tcpdump -XX -i any 'not port 23'

Ignore telnet.

Look for:

• repeated ASCII
• repeated hex
• weird payloads
• beacons
• ICMP payloads

Example

badb eef5 badb eef5

Answer:

badbeef5
