* Immutable Socket API Configuration Constants:
  = socket.AF_INET       -> Map network protocol to IPv4 Address Family.
  = socket.AF_INET6      -> Map network protocol to IPv6 Address Family.
  = socket.AF_UNIX       -> Map network connection locally via file descriptor (IPC).
  = socket.AF_PACKET     -> Direct low-level Linux hardware interface (Raw NIC access). 

  = socket.SOCK_STREAM   -> Enforce sequencing / Connection-Oriented TCP engine.
  = socket.SOCK_DGRAM    -> Enforce Unsequenced / Connectionless UDP engine.

  = socket.IPPROTO_TCP   -> Explicit transport stream routing logic.
  = socket.IPPROTO_UDP   -> Explicit datagram stream routing logic.
  = socket.IPPROTO_ICMP  -> Diagnostics routing logic (Ping / Traceroute payloads).
  = socket.IPPROTO_IP    -> Manages IP headers dynamically; payload managed by user.
  = socket.IPPROTO_RAW   -> Complete manual control over all fields including the IP header.

3. MASTER SOCKET API FUNCTIONS & HANDSHAKE FLOW
-------------------------------------------------------------------------------

* Execution Mechanics Checklist:
  [1] socket()    -> Allocates OS system resource handle and assigns file descriptor.
  [2] setsockopt() -> Fine-tunes low-level buffer parameters and port behavior states.
  [3] bind()       -> Couples socket file descriptor tightly to a local IP and specific Port.
  [4] listen()     -> Transitions bound TCP socket engine into passive ingress monitor state.
  [5] accept()     -> Pops connection off TCP queue; returns specialized communication handle.
  [6] connect()    -> Client side: Targets remote endpoint and runs 3-way TCP handshake.
  [7] close()      -> Instructs OS to purge bindings and tear down open descriptors. 

* Structural Data Pipeline Mechanics:
  - Stream (TCP) Transmitters:
    = s.send(data)       -> Dispatches bytes; returns number of successfully queued bytes.
    = s.sendall(data)    -> Blocks loop internally until entire data buffer clears out completely.
    = s.recv(bufsize)    -> Reads incoming bytes buffer from connected channel state. 

  - Datagram (UDP) Transmitters:
    = s.sendto(data, (ip, port)) -> Transmits un-established individual packets.
    = s.recvfrom(bufsize)        -> Captures incoming bytes data block AND returns (bytes, address). 

* TCP Lifecycle Handshake Sequence Diagram:

  |             CLIENT SOCKET             |             SERVER SOCKET             |

* Blueprint A: Functional TCP Client Blueprint (stream.py)

#!/usr/bin/python3
import socket

def main():
    # Instantiate an IPv4 TCP Stream Socket Descriptor
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM) 
    
    target_ip = '127.0.0.1' 
    target_port = 1111 

    try:
        # Establish structural layer-4 connection boundary
        s.connect((target_ip, target_port)) 
        
        # Strings MUST be packed/prefixed as raw bytes sequences via literal b''
        payload = b'Message\n'
        s.send(payload)
        
        # Capture returning buffer. Preferred size is power-of-2 structure
        data, remote_conn = s.recvfrom(1024)
        
        # Raw incoming network blocks must decode explicitly into structural text
        print(f"[*] Received: {data.decode('utf-8')}")
        
    except Exception as e:
        print(f"[-] Network Exception Occurred: {e}")
    finally:
        # Prevent interface leaks by explicitly closing descriptors
        s.close()

if __name__ == '__main__':
    main()
