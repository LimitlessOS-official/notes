===============================================================================
MAC ADDRESSING
===============================================================================

Length

- 48 bits
- 6 bytes
- 12 hex digits

-------------------------------------------------------------------------------

Formats

- 01:23:45:67:89:AB
- 01-23-45-67-89-AB
- 0123.4567.89AB

-------------------------------------------------------------------------------

Structure

OUI
- First 24 bits
- Vendor portion

NIC Portion
- Last 24 bits
- Device identifier

-------------------------------------------------------------------------------

UNICAST

- One device

-------------------------------------------------------------------------------

MULTICAST

- Group of devices

Example
- 01:00:5E:xx:xx:xx

-------------------------------------------------------------------------------

BROADCAST

- All devices

Address
- FF:FF:FF:FF:FF:FF

===============================================================================
ETHERNET II FRAME
===============================================================================

Destination MAC   = 6 Bytes
Source MAC        = 6 Bytes
EtherType         = 2 Bytes
Payload           = 46-1500 Bytes
FCS               = 4 Bytes

-------------------------------------------------------------------------------

Common EtherTypes

0x0800 = IPv4
0x0806 = ARP
0x86DD = IPv6
0x8100 = VLAN

===============================================================================

MAC Learning

Source MAC -> Port

Stored In

CAM Table

-------------------------------------------------------------------------------

Known Destination

- Forward to correct port

-------------------------------------------------------------------------------

Unknown Destination

- Flood frame

-------------------------------------------------------------------------------

Broadcast

- Flood all ports

===============================================================================
SWITCHING METHODS
===============================================================================

STORE-AND-FORWARD

- Reads entire frame
- Verifies FCS
- Slowest

-------------------------------------------------------------------------------

CUT-THROUGH

- Reads destination MAC
- Fastest
- No error checking

-------------------------------------------------------------------------------

FRAGMENT-FREE

- Reads first 64 bytes
- Drops runt frames
